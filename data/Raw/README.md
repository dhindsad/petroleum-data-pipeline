# Petroleum Data Pipeline

This project demonstrates an end-to-end ETL pipeline using Python to process and analyze petroleum production data.

## Pipeline Steps
1. Extract: Load raw data
2. Transform: Clean and engineer features
3. Validate: Perform data quality checks
4. Load: Store data in SQLite and generate reports

## Tools Used
- Python (Pandas)
- SQLite
- Data Validation Techniques

## Outputs
- Clean dataset
- SQLite database
- Summary report by province

## How to Run
python3 scripts/run_pipeline.py
